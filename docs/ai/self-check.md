# Чек-лист самооценки

Это полная версия списка из [блока 14](https://ykononov.ru/ai-cto/pilot-90-dney/). Отвечайте «да» или «нет»: каждое «нет» становится пунктом плана.

**Подготовка:** baseline снят за 3 месяца. Политика на 1 страницу подписана. ИБ согласовала инструмент и участвует. Бюджет ограничен предохранителями. Цели пилота сформулированы через метрики.

**Пилот:** группа собрана по правилам, сервис типичный. Файлы контекста написаны. Обучение проведено на реальных задачах. Метрики смотрятся еженедельно. Участие ИИ в каждом изменении зафиксировано.

**Результат:** стоимость единицы поставки посчитана и сравнена с baseline. Доля сбойных изменений не выросла. Время ревью под контролем. Использование подтверждено данными инструмента. Эффект ИИ отделён от других изменений.

**Масштабирование:** вторая волна подтвердила результат пилота. Есть платформенная команда. Есть план на случай потери доступа к поставщику. Карьерная лестница и оценка инженеров пересмотрены. Каждое обещание из [блока 02](https://ykononov.ru/ai-cto/zachem-vnedryat-ii/) подтверждено или открыто признано неподтверждённым.

Пример: так чек-лист выглядел у Даниила в день 0, до начала подготовки. Каждое «нет» стало строкой календаря первых 2 недель из [блока 14](https://ykononov.ru/ai-cto/pilot-90-dney/).

| Пункт | Ответ | Что делаем |
| --- | --- | --- |
| Baseline снят за 3 месяца | Нет (есть только 2 показателя из 5) | Дни 2–5: выгрузка из трекера, системы деплоя и баг-трекера |
| Политика на 1 страницу подписана | Нет | Дни 3–6: черновик по шаблону выше, согласование с ИБ и юристами |
| ИБ согласовала инструмент и участвует | Нет | Дни 1–2: встреча, чек-лист для ИБ, назначение участника; дни 3–13: согласование инструмента |
| Бюджет ограничен предохранителями | Нет | Дни 5–7: лимиты 70% / 100% / 15 $ на сессию |
| Цели пилота сформулированы через метрики | Частично (есть «ускориться», нет чисел) | День 14: 2 цели в дизайне пилота |
| Группа собрана по правилам, сервис типичный | Частично (есть энтузиасты, нет скептика и ИБ) | Дни 7–9 |
| Файлы контекста написаны | Нет | Дни 8–12 |
| Обучение на реальных задачах проведено | Нет | Дни 10–13 |
| Метрики смотрятся еженедельно | Нет | День 14: панель из 5 метрик |
| Участие ИИ в каждом изменении зафиксировано | Нет | Шаблон пул-реквеста с отметкой «ИИ: да/нет» |

10 пунктов, 8 «нет», 2 «частично» – и это нормальная стартовая точка. Опасна не она, а пилот, который начинается с такой таблицей без 2 недель на подготовку.

**Небольшая компания:** из чек-листа можно вычеркнуть интеграцию с SIEM, участника от ИБ и формальное согласование инструмента, но нельзя вычеркнуть baseline, политику на 1 страницу, лимит на токены и файлы контекста. Это 4 вещи, которые одинаково нужны и банку на 200 инженеров, и стартапу на 5.
