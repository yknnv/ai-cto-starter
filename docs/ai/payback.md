# Модель окупаемости

> Шаблон. Колонку «Ваши числа» заполните сами. Таблица с автоматическим пересчётом есть на сайте курса: https://ykononov.ru/ai-cto/shablony/#model-okupaemosti

Это структура расчёта на квартал, заполняйте её своими числами. Подробный пример на команде из 10 инженеров с токенами, подписками и дефектами разобран в [блоке 04](https://ykononov.ru/ai-cto/stoimost-tokenov-okupaemost/), здесь только форма и заполненный образец.

| Строка | Как считать | Образец (10 инженеров, квартал) | Ваши числа |
| --- | --- | --- | --- |
| Р1. Подписки | инженеры × цена × 3 | 10 × 40 $ × 3 = 1 200 $ |  |
| Р2. Токены по API | для плана – ориентир (инженеры × 200 $ × 3), для отчёта – факт за квартал из данных инструмента | 10 × 200 $ × 3 = 6 000 $ |  |
| Р3. Своё железо | амортизация + люди, квартал | 0 (нет) |  |
| Р4. Платформенная работа | доля ставки × месяцы × месячная стоимость ставки | 25% × 3 × 5 000 $ = 3 750 $ |  |
| Р5. Обучение | инженеры × часы × стоимость часа | 10 × 8 × 30 $ = 2 400 $ |  |
| **Р. Итого расходы** | Р1 + Р2 + Р3 + Р4 + Р5 | **13 350 $** |  |
| Э1. Единиц поставки до | baseline, деплои за квартал | 50 |  |
| Э2. Единиц поставки после | факт за квартал пилота; если пилот короче квартала, пересчитайте на квартал | 60 |  |
| Э3. Расходы на команду до | люди + инфраструктура, без ИИ | 150 000 $ |  |
| Э4. Стоимость единицы до | Э3 / Э1 | 3 000 $ |  |
| Э5. Стоимость единицы после | (Э3 + Р) / Э2 | 163 350 / 60 = 2 722,5 $ |  |
| Э6. Экономия на поставке | (Э4 − Э5) × Э2; расходы на ИИ уже внутри Э5 | 277,5 × 60 = 16 650 $ |  |
| Э7. Дефектов на проде до / после | баг-трекер | 8 / 9 |  |
| Э8. Стоимость дефекта | часы разбора и исправления × ставка | 3 000 $ |  |
| Э9. Поправка на дефекты | (до − после) × Э8 | (8 − 9) × 3 000 = −3 000 $ |  |
| **И. Итог за квартал** | Э6 + Э9; Р второй раз не вычитаем | 16 650 − 3 000 = **13 650 $** (около 1,17 млн ₽ по курсу ЦБ на 9 октября 2026) |  |

Если И отрицательный через квартал, это нормально; через 2 квартала – повод пересмотреть подход. В веб-версии курса эта таблица интерактивная: заполняются только входные строки (Р1–Р5, Э1–Э3, Э7, Э8), остальные считаются сами.

**Расходы:** лицензии и подписки (число инженеров × цена); токены по API (для плана – ориентир, для отчёта – фактический расход за период); своё железо, если есть (амортизация оборудования + люди на обслуживание, в пересчёте на квартал); платформенная команда (доля ставки × месяцы × месячная стоимость ставки); обучение (часы инженеров × стоимость часа). Всё вместе даёт итог расходов.

**Эффект:** число единиц поставки за квартал до внедрения (baseline) и после него. Стоимость единицы поставки считается так: все расходы на разработку, включая расходы на ИИ, делятся на число единиц. Разница в стоимости единицы × число единиц = экономия или перерасход за квартал. Отдельно считается изменение числа дефектов на проде × средняя стоимость дефекта.

**Итог:** экономия на поставке плюс поправка на дефекты. Расходы на ИИ уже вошли в стоимость единицы после, второй раз их не вычитают. Отрицательный результат через квартал считается нормальным, а через 2 квартала это уже повод пересмотреть подход.
