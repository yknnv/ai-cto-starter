# Чек-лист для ИБ

> Вопросы, на которые нужен ответ до согласования инструмента. Ниже есть пример заполненного чек-листа.

Это вопросы, на которые нужен ответ до согласования инструмента.

- Обучается ли поставщик на наших данных? Есть ли это в договоре?
- Где физически обрабатываются данные? Соответствует ли это 152-ФЗ и отраслевым требованиям?
- Какой срок хранения запросов у поставщика? Можно ли его сократить до нуля?
- Есть ли журнал действий с привязкой к сотруднику? Экспортируется ли он в нашу систему?
- Как инструмент аутентифицирует пользователей? Интегрируется ли с корпоративным входом?
- Какие права получает агент? Можно ли их ограничить по средам и репозиториям?
- Как инструмент защищён от prompt injection? Какие действия требуют подтверждения?
- Что происходит при потере доступа к поставщику? Есть ли план перехода?
- Какие юридические гарантии даёт поставщик по сгенерированному коду?
- Прошёл ли инструмент оценку уязвимостей и когда это было?

Пример заполненного чек-листа по одному из инструментов, которые рассматривал Даниил. Третья колонка – вердикт ИБ, и именно она определяет, идёт ли инструмент в пилот.

| Вопрос | Ответ поставщика | Вердикт ИБ |
| --- | --- | --- |
| Обучается ли на наших данных? | Нет, зафиксировано в договоре, пункт 7.3 | Принято |
| Где обрабатываются данные? | Модель работает в дата-центре поставщика в России, по договору; данные об использовании уходят поставщику | Принято при условии отключения этой передачи или её прохождения через прокси ИБ |
| Срок хранения запросов | Не хранятся после обработки, это зафиксировано в договоре | Принято |
| Журнал действий с привязкой к сотруднику | Да, экспорт в формате JSON по API | Принято, нужна интеграция с SIEM (системой сбора и анализа событий безопасности) до старта |
| Аутентификация | Единый вход (SSO, single sign-on) по протоколу SAML (стандарт, по которому системы передают друг другу данные о входе пользователя), поддерживается | Принято |
| Права агента | Ограничиваются на уровне репозиториев и сред через конфигурацию | Принято, продуктивные среды исключить |
| Защита от prompt injection | Фильтр входящего контента и список действий с подтверждением | Частично: список подтверждаемых действий расширить по политике банка |
| Потеря доступа к поставщику | Инструмент перестаёт работать, пока доступ не восстановят | Принято, план перехода на открытую модель в контуре банка – в течение квартала |
| Юридические гарантии по коду | Возмещение по претензиям о нарушении авторских прав в пределах стоимости договора | Передано юристам |
| Оценка уязвимостей | Внешний пентест в марте 2026, отчёт предоставлен | Принято |

1 «частично», 1 «принято при условии» и 1 «передано юристам» – это нормальный результат. Инструмент пошёл в пилот с условиями, а не был отклонён: ИБ стала участником, потому что её вопросы были заданы до выбора, а не после.
