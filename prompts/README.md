## Как пользоваться

- **В любом чате.** Откройте файл, скопируйте текст из блока кода и вставьте в чат с моделью.
- **С агентом в репозитории.** Попросите: «Прочитай prompts/04-policy.md и действуй по нему». Агент задаст вопросы и предложит сохранить результат.
- **В Claude Code.** То же самое одной командой: `/policy`, `/spec`, `/pilot` и так далее. Команды лежат в `.claude/commands/` и только отсылают к файлам из этой папки.

Используйте модель, которую разрешила ваша служба ИБ. Не вставляйте в ответы секреты, персональные данные и код из закрытых систем.

Порядок для тех, кто только начинает: 01 → 07 → 04 → 03 → 02 → 09 → 10. Перед второй волной: 08.
