# Набор эталонных задач

10 закрытых задач с вашего сервиса за последние 3–6 месяцев с известным правильным результатом. На них сравнивают инструменты перед выбором и проверяют, не стало ли хуже после смены модели или версии инструмента.

На каждую задачу заведите файл `NN-korotkoe-nazvanie.md`:

```
# Название задачи

Постановка: текст из трекера, как его получил инженер.
Начальный коммит: хеш, с которого начинали работу.
Принятое решение: ссылка на пул-реквест или хеш коммита.
Как проверить: команда или тест, который отличает верное решение от неверного.
Результат прогона: дата, инструмент и модель, прошла или нет, сколько правок потребовалось.
```

Не кладите сюда задачи с персональными данными и секретами. Из курса: [блок 14. Практика:](https://ykononov.ru/ai-cto/pilot-90-dney/).
