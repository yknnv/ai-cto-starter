# Спецификации

Спецификация описывает изменение до того, как ИИ пишет код: что сделать, ограничения, критерии приёмки. Агент выполняет ровно то, что написано, поэтому качество спецификации определяет качество кода.

- Шаблон: [_template.md](_template.md). Пример: [0001-example.md](0001-example.md).
- Имя файла: `NNNN-korotkoe-nazvanie.md`, номера идут подряд.
- Для каких изменений спецификация обязательна, записано в `AGENTS.md`, раздел «Порог спецификации».
- В пул-реквесте дайте ссылку на спецификацию: так изменение можно проследить до требований.

Заполнить с моделью: [../prompts/05-spec.md](../prompts/05-spec.md) (в Claude Code: `/spec`). Из курса: [блок 06. Сбор требований](https://ykononov.ru/ai-cto/spec-driven-development/).
